# AlignBA Suite

Build AlignBA, a modern responsive AI-powered workplace productivity assistant for Business Analysts. Create a polished demo-ready prototype centered on the workflow Capture → Analyse → Structure → Communicate → Track → Query → Validate. Include sidebar navigation for Dashboard, Projects, Meeting Summarizer, Requirements, User Stories, Tasks, Smart Email, Research Assistant, Knowledge Chat, Scope Guard, Settings. Seed a complete E-Commerce Checkout Improvement demo project and fictional stakeholder meeting transcript so the 5–10 minute demo flows meeting analysis → extracted requirements → user story/acceptance criteria → executive email → prioritized task → knowledge chat with source → scope guard for Apple Pay → formal change response. Prioritize genuinely usable, structured UI for must-have features, plus task planner, scope guard, citations, approval workflow, productivity dashboard. Make clear responsible-AI safeguards throughout: visible disclaimer, validation states (explicitly stated/AI-inferred/requires validation), review/approve workflows, no fabrication messaging. Make Prompt Engineering a visible area with versioned structured prompt template and testing/refinement indicators. Use professional SaaS design, not generic chat, excellent mobile responsiveness, loading/success/error/regenerate/edit/copy/approve affordances. Enable Lovable Cloud first for persistent per-project data and any AI features. Also create an in-app concise 1–2 page project documentation deliverable section covering problem, users, solution, tools/architecture, prompt strategy/examples/refinement, responsible AI, challenges/solutions, productivity impact and future improvements.
